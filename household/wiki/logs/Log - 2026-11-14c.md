> [!warning] Real open risk — not verified live
> The 2026-11-14 embedding swap (Nomic-v1.5 → Qwen3-Embedding-0.6B) trades retrieval quality for ~4.3x more model parameters (137M → 595M), run via `@huggingface/transformers` **in-process in the Obsidian container, CPU only** — the Second Brain extension has no `baseUrl`/GPU offload option and exposes no quantization (`dtype`) setting, so it likely runs at full fp32. At the vault's current size (~50 notes) this is a non-issue. At real scale (thousands of notes across future family vaults) this is the one piece of the memory architecture that needs a real timed test on the actual RaidLab container — index a batch of ~50 notes and check wall-clock + container CPU, before assuming the swap was free. If it's too slow: fall back to Nomic v1.5, or move to a smaller ONNX embedding model that still beats Nomic without the parameter jump.
