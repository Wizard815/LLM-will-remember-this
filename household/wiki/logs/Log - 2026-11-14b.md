# Log - 2026-11-14b

## Actions

### Short-term / long-term memory split (step 3)
Researched prior art before building: [basic-memory](https://github.com/basicmachines-co/basic-memory) (MCP server, plain Markdown + wikilinks + semantic search, Obsidian-compatible), [obsidian-memory-mcp](https://github.com/YuNaga224/obsidian-memory-mcp) (entity-per-file, Obsidian graph), and the OpenClaw / ReMe pattern (curated long-term file + raw daily logs + scheduled distillation, no vector DB required). Landed on reusing this vault's own existing Ingest/Capture machinery rather than adopting a separate tool — smaller surface area, same guarantees.

- **Added `daily/`** — short-term working-memory folder. One running note per day (`YYYY-MM-DD.md`), wired to the core Daily Notes plugin (`.obsidian/daily-notes.json`) + new `schema/templates/DAILY.md`.
- **Added the Rollover workflow** to [[agents|Agent Constitution]]: yesterday's daily note becomes a `raw/sources/` entry (`status: unprocessed`), then goes through the existing Ingest workflow — no new pipeline, reuses rule 1 (raw immutability) and the existing Ingest step.
- **Formalized Memory Tiers** in `agents.md`: short-term (`inbox/`, `daily/`, `raw/sources/` unprocessed — anything may write here) vs. long-term (`wiki/` — only Ingest/Capture may write here). Automation never writes directly to `wiki/`.
- **Re-enabled the Karpathy LLM Wiki plugin**, scoped to watch `daily/` only, mode `notify` (prompts, never auto-ingests). Gives it the job this vault never had for it: a cheap first-pass entity/concept draft over the day's raw notes, consulted (not trusted) during Rollover.
- Seeded `daily/2026-11-14.md` as a live example; first real Rollover will run tomorrow once it's no longer "today."
